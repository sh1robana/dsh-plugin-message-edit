## 已完成功能

- 用户消息原地保存正文与附件，不请求模型、不新建会话，保留后续对话；保存并发送则通过分支重新生成。
- 助手回复与思考编辑、历史重试、重生成和 Timeline 版本切换。
- 独立的大编辑框；附件增删、替换、粘贴、拖入、图片放大与系统默认程序打开文件。
- 蓝色文件及会话引用；「+」直接添加文件；紧凑的权限、模型与推理等级选择。
- 取消编辑二次确认、快捷键、输入法保护、无修改保存、明暗主题和构建诊断。
- 共享首次读取、后台刷新可用性及刷新与保存协调。

详细功能与安装方法见 [README.md](../README.md)，版本变化见 [CHANGELOG.md](../CHANGELOG.md)。

- 本页是当前进度摘要；工作完成、发布或外部状态发生实质变化时更新。

- 不记录私人对话、凭据、个人配置或未经脱敏的截图；保留日期、结论、必要证据与待办即可。
