## 本机 desktop profile 安装 0.3.2（市场更新失败后的手动处理）

- 需求：维护者用插件市场更新 message-edit，报“更新失败，且更新前的构建未能验证恢复”；要求本机 profile 更新到 0.3.2。
- 原因：profile 中该插件是 `file:` 声明的本地测试构建（0.3.1）。市场更新通道只发 `add`，宿主在 HMR 下对已声明依赖返回 `already-installed`；失败回滚需要按精确版本重装，而 `file:` spec 无法表达，于是恢复校验失败。另外 0.3.2 仍处于 `minimumReleaseAge` 等待期，市场携带的 `--config.minimum-release-age=0` 被官方桌面安装边界拒绝。
- 处理：备份 profile 五个配置文件到 `.local-backups/desktop-20261018-132823-288/`，旧插件 13 个文件到 `.local-backups/plugin-before-032-20261018-132823-288/`；用 profile 自带 pnpm 把 `@sh1robana/dsh-plugin-message-edit` 指向 `artifacts/release-v0.3.2/dsh-plugin-message-edit-0.3.2.tgz` 安装。安装版本 `0.3.2`、发行构建 `dd2956d22ba2bccbd0c2`、目标 `0.2.1-rc.2`。
- 验证：`scripts/check-desktop-install.ps1` 通过（宿主 `0.2.1-rc.2`，双端文件 SHA256 一致）；`pnpm install --frozen-lockfile` 通过；市场自身 `trialValidate` 组合校验 `ok: true`、无重复条目；市场 `/dsh-market/updates` 显示 `current=latest=0.3.2`、`updateAvailable=false`。未重启 DSH，实际加载版本待重启后确认。
- 状态：安装完成，**待彻底退出并重启 DSH 后生效**。
- 下一步：重启 DSH，在页面运行 `__DSH_MESSAGE_EDIT__.diagnostics()` 确认加载构建为 `dd2956d22ba2bccbd0c2`。
- 关联：`file:` 安装来源对应发行包，与 npm `0.3.2` 逐字节一致。

## 修复市场操作失败（锁文件供应链策略）并恢复插件启用

- 需求：维护者反馈插件市场操作再次报错，日志本次会话事件为 `@sh1robana/dsh-plugin-message-edit` 卸载失败。
- 原因：上一条记录中手动安装 `dshmarket@1.66.37` 时绕过 `minimumReleaseAge` 等待期，但漏把它写入 profile 的 `minimumReleaseAgeExclude`。此后 pnpm 每次校验 lockfile 都报 `ERR_PNPM_MINIMUM_RELEASE_AGE_VIOLATION`（1.66.37 发布未满 24 小时），市场的 `remove`/`add` 因共用 pnpm 全部失败。这次失败还使 message-edit 被移出 `dsh.profile.bundles`、处于停用。
- 处理：在 profile `pnpm-workspace.yaml` 的 `minimumReleaseAgeExclude` 追加 `dshmarket@1.66.37`（修复前配置备份于 `.local-backups/desktop-policyfix-20261018-133142-031/`）；通过市场 `toggle` 接口重新启用 message-edit，市场写回 `dsh.profile.bundles` 与补丁行 `- id: message-edit disabled: false`。
- 验证：`pnpm install --frozen-lockfile` 通过（supply-chain 校验 5 条通过）；`/dsh-market/installed` 显示 message-edit `state=live`、`bundle=true`、`unbundled` 为空，市场返回 `restart=false`、`refresh=true`。
- 状态：已完成，市场页面刷新后即可看到启用状态。
- 下一步：市场内对**已安装插件**的“更新”仍受宿主 HMR 限制（`installBundle` 对已声明依赖返回 `already-installed`），本地 `file:` 插件继续用 `scripts/install-desktop.ps1` 更新；是否向 DSH 上游反馈该限制由维护者决定。
